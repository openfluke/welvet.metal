# welvet.metal gap census

**Version `0.68`** — audited engine board **68/100** using individual subgates
(2026-10-26). The score measures engine completion, separately from numerical
parity. The [README](README.md) contains the board and checklist;
[VERSIONING.md](VERSIONING.md) defines the calculation. This is a working-tree
milestone, not a newly published Git release.

The runtime census is generated by `src/gaps/registry.cpp`:

```sh
./scripts/build_macos.sh
./build/welvet_dense_fwd --version
./build/welvet_dense_fwd --identity
./build/welvet_dense_fwd --gaps
./scripts/macos_build_w2a.sh --training-all
```

## Verified

| Scope | Evidence |
|---|---|
| macOS Apple silicon shared/static backend | Device, embedded shaders, command dispatch, buffers, C ABI and wire tool |
| All 23 supported layer baselines | Metal forward/backward and native GPU SGD; GDN Float32 only |
| Native FormatNone parameter dtypes | All 34 encodings with the current Float32 tensor interface and declared software precision |
| All 29 numbered training modes | Go↔Metal leaf, Line, mesh-clock and shared-volume evidence in w2a |
| KMeans / ordinary Parallel | Both outputs, seven combines, gate/state and polymorphic/nested branches |
| Advanced training / Cameral | Freeze, Shadow, Adversarial, Memory, mixed branch modes/rates, nested Stack overrides and upstream gradients |
| CamSync / BlendStores | GPU means/blends/native repacking, biases, frozen exclusions, groups/cross endpoints and sync events; exact reset replay |
| GPU-only enforcement | Host numerical APIs rejected; host scheduling, allocation, copies and storage staging permitted |
| Numerical parity | Best effort aiming for 100%, accepting 60–100% on w2a's industry-to-exact spectrum; deviations reported |

See [TRAINING_CHECKLIST.md](docs/TRAINING_CHECKLIST.md) for dated per-mode and
per-layer sign-off, and [METAL_ONLY.md](docs/METAL_ONLY.md) for the execution
contract. Historical CPU-backed results do not establish GPU support.

## Remaining

- Packed quant formats beyond FormatNone and broader tensor/tiling APIs.
- Broader attention/convolution/state variants and the seqmix ConvMix implementor.
- Persistent graph/tape/gradient residency, dispatch reduction and peak fusion.
- DNA, evolution, TANHI and telemetry beyond the completed Tween credit paths.
- Tokenizer, ENTITY/checkpoints, transformer generation, sampling and HF loading.
- Go NAC integration, release packaging, clean-environment distribution checks,
  and iOS artifacts. ANE remains a separate backend gate.

Apple GPU compute has no hardware Float64; supported kernels use explicit
software-promoted arithmetic where required. Tiny models can be dominated by
dispatch and staging overhead. Correctness sign-off does not imply a speed win
or completion of persistent GPU residency.
